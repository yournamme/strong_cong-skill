# 图文转视频（公众号文章 → 短视频制作四件套）

## 核心公式（不可违背）

「视频给故事+卡片，图文给细节+清单」。同一条内容两个平台各存一份文件，互挂双链。

## 输入

- 用户粘贴的公众号文章全文；若只给链接，先抓取全文再继续。
- 可选参数：平台（默认 B站 竖屏 9:16）。若指定其他平台，只调整画幅和节奏说明，四件套结构不变。

## 转化流程（严格按 4 步走）

1. **只抽一个问题**：通读全文，选出「一句话能讲痛」的那一个问题。一条视频只救一个问题。若文章里有多个候选问题，列出候选让用户挑一个，不要自行合并。
2. **砍成四段式**：钩子 → 共情 → 3 个要点 → 金句。口播稿全文 ≤220 字。
3. **凝成卡片**：每个要点凝成一条 ≤15 字的 UI 卡片文案；文章的清单小标题现成可用，优先复用原文小标题。
4. **建拍摄包**：给出可直接执行的任务清单，文件顶部双链回原文（用用户提供的原文标题/链接占位）。

## 内容深化三层（觉得稿子浅时必走）

从文章里挖一个反常识的坑，补三层再揉成故事：

- **为什么**（机理）：这件事底层的因果是什么
- **规律**（通用性）：它还能套到哪些场景
- **观众能带走什么**（行动价值）：看完能立刻做的一件事

**红线**：不要方法论名词堆砌（「批量扫参」「分层优化」这类抽象词是反例），要具体、有画面、有人味。

## 人设（口播稿必须符合）

不装、踩坑实录、一点点变 better。口语感，允许轻微自嘲，不要 AI 腔。第一人称，讲"我"的亲身经历，不讲大道理。

## 输出四件套（缺一不可，按此顺序）

### 1. 口播稿

- 结构：钩子 → 共情 → 3 个要点 → 金句，分四段排版
- 分段字数预算（写作时就按这个刻度写，不要写完全文再砍）：
  - 钩子 ≤30 字（一个具体数字或反常事实，参考标准例句：「我收藏了 200 多个 AI 提示词模板，你猜我用过几个？三个。」）
  - 共情 ≤40 字（描述"你也一样"的具体场景）
  - 3 个要点合计 ≤90 字（每条一个完整短句，不堆术语）
  - 金句 ≤25 字（一个生活化类比）
  - 全文 ≤220 字
- 交付时在每段后面用括号标注实际字数，例如「（27字）」，让超限无处可藏
- 写完后"自己念一遍"：检查是否有拗口连读、超过一口气读不完的长句，卡嗓子的地方必须改顺
- 禁用词自查：出现「批量扫参」「分层优化」「赋能」「闭环」这类词一律重写成具体场景

### 2. UI 卡片文案

共 4 张卡，对应口播稿四段：

- 卡片1 · 钩子卡（≤15字）
- 卡片2 · 共情卡（≤15字）
- 卡片3 · 要点卡：一张卡内含 3 条要点文案，每条 ≤15 字
- 卡片4 · 金句卡（≤15字）

优先复用原文的清单小标题；每条单独数字数。

### 3. 分镜 + 生图提示词

- 按口播稿切 5-6 个镜头，每个镜头给：镜头序号、对应口播句、一句话画面描述、一段即梦/生图提示词
- **角色锚点图机制（形象统一的关键，不可跳过）**：生图工具是无状态的，纯文字描述人物必然每张都漂移。必须先有锚点图：
  - 先问用户是否已有角色锚点图（如 `角色锚点图-绿卫衣v1.png`）。有：记录其路径，写进每条提示词的参考说明。没有：第一条提示词先生成锚点图（正面半身像、纯色背景、无动作），命名 `角色锚点图-v1.png` 存入拍摄包，验收后作为后续所有镜头的参考图
  - 每条镜头提示词分两部分：【参考图】注明"上传角色锚点图作为参考图，人物长相、发型、服装以参考图为准"；【文字描述】画面动作与构图
  - 文字部分仍保留统一形象描述（年龄/发型/穿着/画风），作为参考图的兜底，但一致性以锚点图为准
- 提示词硬性约束（每条提示词都要包含）：
  - 竖版 9:16
  - 浅色纯色背景（米白/浅灰/浅蓝任选其一，全套镜头统一）
  - 画面上方约三分之一留白（放 UI 卡片用）
  - 画面中不出现任何文字

### 4. 拍摄包骨架

输出可直接执行的任务清单，含时间线模板：

- 文件顶部放双链：回链原文（原文标题+链接），原文处也应加回链指向本视频文件（提醒用户手动补）
- 建议文件结构：
  ```
  拍摄包_【视频标题】/
  ├── 00_双链与选题说明.md   ← 顶部双链回原文
  ├── 01_口播稿.md
  ├── 02_UI卡片文案.md
  ├── 03_分镜与生图提示词.md
  ├── 04_发布检查清单.md
  └── assets/
      └── 角色锚点图-v1.png   ← 形象统一的基准，后续镜头都拿它当参考图
  ```
- 时间线模板（按用户"周更"节奏，可按需平移）：
  - D1 上午：先生成/确认角色锚点图并存入 assets/，再按提示词逐镜头生图（每镜都上传锚点图做参考），逐镜头验收（与锚点图形象是否一致 / 上方是否留白 / 有无文字穿帮）
  - D1 下午：录口播，按四段分段录，卡壳处重录单段
  - D2 上午：剪映合成——贴卡片、对轴、加字幕
  - D2 下午：导出竖版 9:16，自查一遍后发布，补原文回链

## 明确不做（边界）

- 不做录音、不碰剪映、不代发布
- 不生成封面
- 一条视频只处理一个问题，不做多选题合并
- 只输出文本交付物；生图动作由用户拿提示词去即梦执行

## 交付前自查清单

逐项确认后再交付：

1. 四件套齐全，且卡片、口播稿、分镜讲的是同一个故事
2. 口播稿各段都在字数预算内（钩子≤30 / 共情≤40 / 要点合计≤90 / 金句≤25，全文≤220），每段已标注实际字数，念得顺，无名词堆砌
3. 卡片每条 ≤15 字
4. 分镜 5-6 个，每条提示词含：9:16、浅色纯色背景、上方留白、无文字、锚点图参考说明
5. 角色锚点图已明确：路径已有，或第一条提示词就是生成锚点图
6. 拍摄包含双链占位、assets/锚点图位和时间线模板

## 使用示例（浓缩版）

输入：一篇讲"收藏了 200 个 AI 提示词模板却几乎没用过"的公众号文章。

输出节选：

- 口播稿钩子：「我收藏了 200 多个 AI 提示词模板，你猜我用过几个？三个。」（27字）
- 金句：「提示词跟健身卡一个道理——办了不用，等于没办。」（23字）
- 钩子卡：「200 个模板，只用了 3 个」
- 镜头3 画面：人物把提示词卡片像邮票一样贴进厚厚的收藏册；提示词：「【参考图】上传 assets/角色锚点图-v1.png，人物长相、发型、服装以参考图为准。【文字描述】竖版9:16，浅米色纯色背景，上方三分之一留白，画面无文字，3D黏土风戴眼镜的年轻男生，正把一叠卡片贴进厚厚的收藏册，表情满足又麻木」
